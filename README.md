
# Project Title

A brief description of what this project does and who it's for

This project is based on the use of aws cloud services lambda and dynamoDB.
Using the HTML, CSS the project is fully coded and ready to use as a website.
In which we can create our to do list by logging with our college if and password.
## Deployment

To deploy this project run

```bash
  npm run deploy
```


## Features

- Light/dark mode toggle
- Live previews
- Fullscreen mode
- Cross platform
